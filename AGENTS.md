# Agent rules

Read first, in order: this file, `docs/DECISIONS.md`, the task you were given
in `tasks/`.

- Work on a branch named after the task (`task/T-0001-slug`), never on the
  default branch.
- Run `fk gate` before asking for review.
- Never edit `.github/`, `foundation.toml`, `.foundation/` or `.gitleaks.toml`
  unless the task says so; those are control files and need a human label.
- Never commit secrets. Configuration examples go in `.env.example`.
